本项目 Lua 文件处理 XML/CDATA 内容时的固定规则：`]]>` 中含有 `]]`，会提前终止 `--[[ ... ]]` 块注释和 `[[ ... ]]` 长字符串，导致语法错误。涉及 XML/CDATA 内容的注释与长字符串必须改用 `[=[ ... ]=]` 分隔符，且避免在块注释中出现 `]]>`。此问题在 xml.lua 头部注释和测试文件长字符串中各实际触发过一次。
